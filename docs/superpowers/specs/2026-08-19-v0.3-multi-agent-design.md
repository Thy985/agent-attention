## 1. 产品定位

```
v0.1: "叫我回来"
v0.2: "让我这个 Agent 自己接入"
v0.3: "让我在一个小窗口里看到整台电脑上的 Agent"
```

**一句话**：把本机所有已注册 Agent 的 Attention 事件，通过 Tray 入口在一个轻量 Center 窗口里按 Agent 分组展示，点击可跳回对应 Terminal。

**核心问题**：v0.2 解决单个 Agent 通知到位；v0.3 解决用户在一台机器上运行多个 Agent 时，能从一个小窗口区分"谁在喊、喊了什么、去哪处理"。

---

## 2. 核心原则（冻结）

### 原则 1：Agent 自注册是唯一合法的 Registry 写入口

```
❌ Attention Center daemon 扫描进程 → 自动写入 agents.json
✅ Agent 自己加载 Skill → 自己执行 register → 写入 agents.json
```

### 原则 2：Onboarding ≠ Discovery

```
Onboarding（允许）:
  开发 Agent（如 Claude Code）
    ↓ 发现本机有哪些 Agent CLI（which / Get-Command）
    ↓ 帮助安装 Skill
    ↓ 提示目标 Agent 加载 Skill
    ↓ 目标 Agent 自己 register
    ↓ 验证注册成功

Discovery（禁止）:
  Attention Center daemon
    ↓ 扫描进程 / 环境变量
    ↓ 猜测 Agent 身份
    ↓ 自动写入 agents.json
```

### 原则 3：Target Jump 是 best-effort

Jump 失败 → Attention Center 正常 → State 正常 → Toast 正常。仅打印 warning。

---

## 3. 明确边界（不做什么）

以下事项**显式 defer 到 v0.4+**：

- ❌ Agent 自动发现（进程扫描 / 环境变量猜测）
- ❌ TeamMind RuntimeEvent 订阅（70+ 事件类型）
- ❌ Task graph / sub-agent topology
- ❌ MCP / ACP / Hook 集成（除 `agent-notify` CLI 外）
- ❌ Notification Action 按钮（Allow/Deny）
- ❌ Quiet Hours / Focus Awareness
- ❌ 多用户路由
- ❌ Agent 间事件关联/聚合
- ❌ macOS / Linux Tray 适配
- ❌ IDE Target Jump（仅 Terminal PID）
- ❌ capabilities / color / version / integration 字段

**这些不属于"人在一个小窗口里管理 Agent 注意力"的核心路径。**

### 4.1 Phase 1: Agent Onboarding（核心新增）

**注意**：这是 v0.3 的"接入流程"，不是 Attention Center 的运行时功能。

#### Onboarding 流程

```
开发 Agent（如 Claude Code）
    │
    │  Step 1: 探测本机 Agent CLI
    ├─→ Get-Command codex / atomcode / qwenpaw
    └─→ 得到: [codex, atomcode, qwenpaw]
    │
    │  Step 2: 读取目标 Agent 的插件/技能安装方式
    ├─→ codex plugin list
    ├─→ atomcode plugin marketplace list
    └─→ 找到: 如何安装 skill/plugin
    │
    │  Step 3: 帮助安装 Agent Attention Skill/Plugin
    ├─→ 复制 skills/agent-attention/ → 目标 Agent skill 目录
    └─→ 写入目标 Agent 的配置文件
    │
    │  Step 4: 目标 Agent 自己加载 Skill 并 self-register
    ├─→ 目标 Agent 执行: agent-attention agent register codex "Codex"
    └─→ 写入 ~/.agent-attention/agents.json
    │
    │  Step 5: 验证
    ├─→ agent-attention agent list
    ├─→ agent-notify completed "onboarding test"
    └─→ 检查 Toast + State + Center
```

#### 开发 Agent 的 Onboarding 规则（加入 CLAUDE.md）

```markdown
## Agent Onboarding Rule

When asked to connect another locally available Agent to Agent Attention:

1. The current agent may inspect the local environment to identify
   available Agent CLIs (which / Get-Command / where).
2. The current agent may execute the target Agent's installation/
   configuration commands when permitted.
3. The current agent MUST NOT directly create or modify the target
   Agent's Agent Registry record in agents.json.
4. The target Agent must load the Agent Attention Skill and
   self-register via `agent-attention agent register`.
5. The current agent must verify the target Agent's registration
   by checking agents.json AND emitting a real test Attention event.
6. Do not report "Agent connected" until registration and
   notification have been verified.
7. If the current agent claims user intervention is required,
   it must first document the exact operation it attempted and
   why available tools could not complete it.
```

#### 目标 Agent 兼容性评估

| Agent | CLI 可用 | 插件系统 | Onboarding 难度 | 推荐度 |
|-------|----------|----------|----------------|--------|
| atomcode | ✅ | marketplace (407 plugins) + hooks | ★ Easy | ★★★★★ |
| codex | ✅ | marketplace + config.toml | ★ Easy | ★★★★★ |
| dsh | ✅ | profile-based | ★★★ Hard | ★★ |
| qwenpaw | ✅ | agent management + ACP | ★★ Medium | ★★★ |

**v0.3 首选目标**：atomcode + codex（插件系统清晰，启动快）
**v0.4 扩展目标**：qwenpaw（ACP 接口需研究）
**暂不支持**：dsh（配置复杂，不适合快速 Onboarding）

**连接状态算法**：
```typescript
function getConnectionStatus(agent: Agent): 'connected' | `last-seen-${minutes}` {
  const minsAgo = Math.floor((Date.now() - agent.last_seen_at) / 60000);
  if (minsAgo < 5) return 'connected';
  return `last-seen-${minsAgo}`;
}
```

**优先级颜色**（Center 内部分配，不从 Agent 读取）：
- P0 = 🔴
- P1 = 🟡
- P2 = 🟢

**点击事件行为**：
- 有 target → 尝试 Jump（best-effort）
- 无 target → 显示详情弹窗
- Jump 失败 → 仅 warn，不影响 Center

## 9. Phase 4: Target Jump（best-effort）

**v0.3 只做**：Windows + terminal PID focus。

```typescript
async function jumpToTarget(target: AgentTarget | null): Promise<void> {
  if (!target || target.type !== 'terminal') return;
  try {
    await focusProcess(target.pid);
  } catch (err) {
    console.warn(`[agent-attention] jump to PID ${target.pid} failed: ${err}`);
  }
}
```

**失败降级**：仅打印 warning，不影响 Center / State / Toast。

## 11. 新 CLI 命令

```bash
# 注册 Agent（最少字段）
agent-attention agent register claude-code "Claude Code"

# 列出所有 Agent（含连接状态）
agent-attention agent list
# 输出：
# ● claude-code  (Claude Code)  ·  Connected
# ○ codex        (Codex)        ·  Last seen 8 min ago

# 设置 Target（点击跳转目标）
agent-attention agent target set claude-code terminal --pid 12345

# 清除 Target
agent-attention agent target clear claude-code

# 打开 Center 窗口
agent-attention center open
```

## 15. 已知限制（v0.3）

1. **Target Jump 仅支持 Windows terminal PID**。macOS/Linux 不支持。
2. **Agent 身份由 Agent 自注册**，无自动发现。
3. **Center 窗口仅 Windows**（WPF）。macOS/Linux 暂不支持。
4. **不改 state.json schema**，向后兼容 v0.2。
5. **per-agent unread 统计基于 state.json 扫描**，O(N) 开销。v0.4 可加 index。
6. **Onboarding 依赖开发 Agent 有 Shell 执行权限**。
