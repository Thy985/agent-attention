## v0.3 Onboarding 策略建议

基于以上验证，建议：

### Phase 1 (v0.3 核心): atomcode + codex Onboarding

**理由**:
1. atomcode 和 codex 都有明确的插件/技能系统
2. 插件安装命令简单: `atomcode plugin install` / `codex plugin add`
3. Hook/配置机制清晰: `~/.atomcode/hooks.json` / `~/.codex/config.toml`
4. 启动速度快，适合自动化 Onboarding

**Onboarding 流程**:
```
开发 Agent (Claude Code)
    ↓
1. 探测本机 Agent CLI (which/get-command)
    ↓
2. 检测 atomcode/codex 是否已安装
    ↓
3. 帮助安装 agent-attention Skill/Plugin
    ↓
4. 配置 atomcode hooks 或 codex config
    ↓
5. 启动目标 Agent 并让它 self-register
    ↓
6. 验证注册成功 (agents.json)
    ↓
7. 发送测试通知 (agent-notify)
    ↓
8. 验证 Toast + State
```

### Phase 2 (v0.3 后续): dsh + qwenpaw Onboarding

**理由**:
1. dsh 配置复杂（profile-based），不适合快速 Onboarding
2. qwenpaw 需要研究 ACP 接口，工作量大
3. 可以先验证 atomcode + codex 的流程，再扩展

### 不建议做的事

- ❌ 不创建 `src/discovery.ts`（违反原则 2）
- ❌ 不在 v0.3 支持 macOS/Linux（平台限制）
- ❌ 不在 v0.3 支持 TeamMind RuntimeEvent（defer to v0.4+）
