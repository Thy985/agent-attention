## 已知限制

1. **Target Jump 仅支持 Windows terminal PID** — macOS/Linux 暂不支持
2. **Agent 自动发现依赖环境变量** — 真实身份由 Agent 自注册
3. **Per-agent unread 基于 state.json 扫描** — O(N) 开销，v0.4 可加 index
4. **不改 state.json schema** — 向后兼容 v0.2
