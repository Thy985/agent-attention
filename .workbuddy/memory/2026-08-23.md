## C# 构建清理坑（可复用）

- 清理 `dotnet build` 产物时，Roslyn **`VBCSCompiler.exe` 编译服务器**会长期持有 `VBCSCompiler\AnalyzerAssemblyLoader\...\*.dll` 文件锁 → `shutil.rmtree` / `rm -rf` 报 `PermissionError [WinError 5]`。
- 正确清理顺序：`taskkill /IM VBCSCompiler.exe /F` → 再 `rmtree`。沙箱 safe-delete（recycle bin）对 D:/Temp 会 fail-closed，python `shutil.rmtree` 直删可绕过，但必须先杀 VBCSCompiler 释放锁。
- 对迁移 CI/脚本的影响：清理 csharp 构建目录前务必先停 VBCSCompiler，否则增量清理会失败。

## 架构评审 → 迁移文档 v2 重构（行为对等迁移）

- 用户严审旧迁移文档，核心修正：**PowerShell→C#（载体迁移）与 文件轮询→Named Pipe（通信模型迁移）必须解耦**，否则行为异常难归因。路线从 P0-P4 改为 **M0-M7 每步单一变量**：M0 契约冻结 → M1 C#单Host+文件模型等价 → M2 Tray parity → M3 Center parity → M4 全链路对等 → M5 Pipe单向通知 → M6 Pipe接管+文件fallback → M7 删PowerShell。
- 新增 `docs/behavior-contract.md`（M0 交付物）：CLI/State/Registry/Tray/Center/Command/Target 七类契约 + 命令集（真实：`mark-all-read`/`mark-event <id>`/`jump <agent-id>`/`agent register|list|target set|clear`；`open-center` 非 daemon 命令、单Host内直拉） + 行为对等测试矩阵。铁律：C# 只实现语义不重定义。
- 角色重定义：daemon = local UI coordinator / control-plane endpoint（可接受命令），State/Registry=truth，C# Host=桌面UI宿主。旧"daemon 仅作 UI 进程"表述作废。
- 单 Host 结构建议：一个 `AgentAttention.UI.exe`（WinForms Tray + WPF Center 同源），生命周期从 daemon/tray/center 三进程降为 daemon/UIHost 两进程；`open-center`/Target Jump 进程内完成，不经 Node/Pipe。
- Pipe 简化：M5 仅单向通知（`state-changed`/`registry-changed`/`daemon-status`）；消息只留 `state-changed`（revision+unreadCount），删冗余 `event-pushed`/`unread-changed`；重连后重建全量 snapshot。ACL 必须实机验证（当前用户PASS/SYSTEM PASS/其他用户DENIED），`FirstPipeInstance` 不替代生命周期锁。
- 验收语言修正：删"90% bug 消失"，改为"消除一类已识别的 PowerShell-host 特有缺陷，不证明系统级可靠性"。
