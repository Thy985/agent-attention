3. **Dedup 分隔符碰撞** — `src/dedup/index.ts:13` 用 `sha1("agent:event:message")`；`agent="a",event="b:c",msg="d"` 与 `agent="a:b",event="c",msg="d"` 哈希相同 → 第二个被错误抑制。已复现。
4. **Agent 自动识别全部退化成 'agent'** — `registry.ts:detectAgentId()` 检查 env(`CLAUDE_CODE`/`CODEx`/`OPENAI_WORKERS`) 与 `process.execPath.includes('claude'/'codex')`；但 CLI 运行于 node.exe，execPath 永不匹配 → `autoDetectAndRegister()` 永远返回 'agent'。已复现。违反 v0.3 规格 §3 原则2（禁止自动发现），且 start 完全不清理 = 无界增长（Scenario B/D=3 after x3）。
  - CIM 不可用时 killStaleTrayProcesses 静默 no-op（catch{}），孤儿永不被回收。
- 根因：(1) (daemon-cli.ts:86-118) 无 killStale 调用；(2)  依赖 Get-CimInstance *TrayIcon* 子串匹配且 catch 静默；(3) daemon.ts:181 算了 tray.pid 但从未写入文件 → tray 生命周期只存在易失的 in-memory 变量，daemon 一死即失主、无记录可精确回收；(4) install-daemon.ts:57-71 只按 PID 杀旧 daemon，不杀旧 tray。

## 隐藏图标专项批判（18:40）
- 致命：每次 `daemon stop` 都泄漏幽灵图标。`daemon.ts:189` 用 `trayProc.kill('SIGTERM')`，Windows 上 Node 把 SIGTERM 映射成 TerminateProcess（硬杀），tray 的 `Invoke-Exit`（唯一 `Visible=$false`，TrayIcon.ps1:286）永不被调用 → 图标停在 systray 直到鼠标悬停才回收。注意：前轮"优雅 stop 不漏进程"指进程，图标是独立 shell 资源，仍泄漏。
- tray 自身信号处理全死：`trap`（:32）只 ReleaseMutex 不隐藏图标；`:307 Register-WinEvent = ${}` 无效；`:324` 在 PSConsoleHost 注册不存在的 ControlC 事件；`:317 $consoleHandler` 从未引用。Ctrl+C/关闭均不触发优雅隐藏。
- 严重/产品缺陷：图标 `Visible` 恒为 `$true`（:233），`Update-NotifyIcon` 只改颜色/badge 不切换 Visible，无"0 未读自动收起"逻辑。
- 组合灾难：前轮 crash→start 每轮 +1 孤儿 tray，每个孤儿图标永久不收起 → 溢出区堆满死图标，需逐个鼠标悬停清除。
- 修复：daemon 改发 sentinel（写 tray-state.json `exit:true` 或 signal 文件）让 tray 轮询到后优雅 Invoke-Exit；trap/循环包 try-finally 隐藏图标；按 unreadCount 切 Visible。
